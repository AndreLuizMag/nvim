# Neovim
### Navigation

| Key      | Action                               |
| -------- | ------------------------------------ |
| `<C-w>h` | Move the cursor to the left window   |
| `<C-w>j` | Move the cursor to the bottom window |
| `<C-w>k` | Move the cursor to the top window    |
| `<C-w>l` | Move the cursor to the right window  |

## Ordering

| Key      | Action                             |
| -------- | ---------------------------------- |
| `<C-w>H` | Move the column to the left side   |
| `<C-w>J` | Move the column to the bottom side |
| `<C-w>K` | Move the column to the top side    |
| `<C-w>L` | Move the column to the right side  |
| `<C-w>L` | Routate the windows to the right   |
| `<C-w>R` | Routate the windows to the left    |

# Plugins

## neo-tree.nvim
`?` - For help


### Painel

| Key     | Action                   |
| ------- | ------------------------ |
| `q`     | Close the painel         |
| `e`     | Toggle auto expand width |
| `R`     | Refresh                  |
| `space` | Toggle node              |
| `z`     | Close all nodes          |

### File

| Key | Action          |
| --- | --------------- |
| `a` | Add new file    |
| `r` | Rename the file |
| `d` | Delete file     |

### Open file

| Key | Action                     |
| --- | -------------------------- |
| `s` | Open vertical split vew    |
| `S` | Open horizontal split view |
| `t` | Open in new tab            |
| `w` | Open in peekaboo mode      |
### Tabs

| Key       | Action                 |
| --------- | ---------------------- |
| `gt`      | Go to the next tab     |
| `gT`      | Go to preview tab      |
| `<num>gt` | Go to the specific tab |
| `:tabn`   | Similar to `gt`        |
| `:tabp`   | Similar to `gT`        |
| `:q`      | Close actual tab       |
| `:tabc`   | Similar to `:q`        |
