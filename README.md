
# Nvim IDE

## Dependences

### Fira code nerd

Download the [Fira Code Nerd Font](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/FiraCode.zip) and set this font on your terminal

### C Compiler

On Linux you have the `gcc` for compile the C code, but on the Windows you need to install a compiler

```
winget install zig.zig
```


## Initial setup

### Linux

Clone this repository on `~/.config/`


### Windows

Clone this repository on `C:\Users\USERNAME\AppData\Local\`
